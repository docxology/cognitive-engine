# Reproducibility

The repository includes an offline test with the literal inputs and assertions. The manuscript README specifies the Python and NetworkX versions used for those checks and records how to export the fixture observation as JSON and derive the Graphviz figure. The source revision is recorded in the bibliography. The test and figure generator use the standalone symbolic modules and require no model files, credentials, or service calls. Archived project outputs are retained in their original directories and are not used as measurements in this report.
