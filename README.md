# Cognitive Engine

Cognitive Engine is a Python prototype with symbolic representations,
memory components, and a probabilistic pathway. The symbolic modules
can be inspected independently of the hybrid engine.

- [Documentation](docs/README.md) provides setup and a map of the repository.
- [Local verification](docs/quickstart.md) exercises parsing, bindings, and a template
  using fixed inputs.
- [Technical manuscript](docs/manuscript/README.md) reports the measured
  symbolic behavior and the pinned render procedure.
- [Citation](CITATION.cff) and [license](LICENSE) identify the software.

The project also includes a separate TypeScript fixture layer.
Archived reports, coverage, model files, and visualizations record
earlier experiments.
